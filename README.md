# BioNexus 점심 고르기

출근한 사람을 체크하면 그 사람들이 좋아하는 메뉴는 위로, 싫어하는 메뉴는 아래로 정렬해 주는 웹 페이지입니다.

## 실행
빌드 없이 `index.html`을 브라우저에서 열면 됩니다. (GitHub Pages로도 바로 배포 가능)

## 데이터 수정
`data.js` 하나만 고치면 됩니다.
- `MENUS`: 메뉴 이름, 이모지, 태그
- `OFFICES.gangnam.people`: 사람별 `likes` / `dislikes` 태그 (±1)

점수 = 그 메뉴를 좋아하는 사람 수 − 싫어하는 사람 수 (한 사람당 1점).
점수가 같으면 원래 순서를 유지합니다. "한 명이라도 싫어하면 아예 숨기기"를 켜면 누군가 싫어하는 메뉴는 목록에서 빠집니다. 광교1·광교2는 `people`을 채우면 바로 활성화됩니다.
