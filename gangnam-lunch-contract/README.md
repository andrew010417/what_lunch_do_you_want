# 강남 점심 계약 식당 고르기

강남 사무실에서 계약할 점심 식당 후보 8곳을 지도에 표시하고, 한 곳씩 다녀올 때마다 평가를 남겨 순위를 보는 페이지입니다.

👉 **바로 사용하기: https://andrew010417.github.io/what_lunch_do_you_want/gangnam-lunch-contract/**

제작 · 분석팀 박재형 (Claude Code로 개발)

## 사용 방법
1. 주소를 열면 지도에 후보 8곳이 번호 핀으로 보여요. 핀이나 이름을 누르면 후기 링크 · 카카오맵 · 길찾기
2. 다녀온 뒤 **✍️ 다녀왔어요 · 평가 남기기** → 별점(0.5점 단위) · 이름 · 다녀온 날 · 한줄평 → 저장 (로그인 필요 없음)
3. 같은 곳을 여러 번 가도 갈 때마다 남기기. 맨 위 **🏆 현재 순위**에서 평균 별점 순위 확인

## 파일
| 파일 | 내용 |
|---|---|
| `index.html`, `style.css`, `tour.css` | 화면 |
| `app.js` | 동작. 맨 위 `PRESET`이 후보 목록 |
| `config.js` | 카카오 키, Supabase 주소·키, 기준 사무실 |

## 관리자 안내
- 평가는 Supabase `lunch_docs` 표의 `ratings`(id가 `vt_`로 시작), 위치 수정은 `restaurants`(id가 `tour_`로 시작)에 저장돼요. BioNexus 점심 고르기와 같은 Supabase 프로젝트를 써서 따로 설정할 것이 없어요.
- 카카오 지도는 카카오 개발자 사이트에 등록한 도메인에서만 떠요. 다른 주소에 올리면 그 도메인을 **JavaScript SDK 도메인**에 추가해 주세요.
